## Висновки

- У цьому прикладі **Boyer–Moore** дає найменший час у всіх чотирьох клітинках: на довших текстах і на обраних шаблонах зсуви з кінця рядка зменшують кількість порівнянь символів.
- **KMP** посідає середнє місце: передбачувана лінійна поведінка, але без таких великих «стрибків» по тексту, як у спрощеній реалізації Боєра–Мури.
- **Rabin–Karp** тут найповільніший через накладні витрати на хешування зрізів і підтвердження збігів при колізіях хешу.
